# Multi-Currency Financial Data Staging & ETL Engine

 Business Problem
Automating data cleaning, FX rate conversion, and transaction staging for international financial datasets.

 Tech Stack & Methods
* **Core Tool:** Microsoft Excel (Advanced)
* **ETL Engine:** Power Query
* **Formulas & Reporting:** Dynamic Array formulas, Pivot Tables, Currency Normalization

 Key Implementation Details & Results
* Built automated Power Query steps to ingest, clean, and deduplicate heterogeneous cross-border transaction logs.
* Converted dynamic foreign exchange values to base currencies (USD/INR) for standardized reporting.
* Created scalable summary staging tables ready for automated downstream accounting workflows.
